# Daedalus · 代达罗斯

**统一采集与感知引擎（不是爬虫）** — Universal Data Acquisition & Observation Engine

> 单机、Windows 优先。三种采集环境（直连网络 / 浏览器运行时 / 制品与媒体）是**可被调用的执行资源**，
> 由证据驱动的路由按「便宜先行」（L0→L5）选择路径；**永远先捕获原始事实，再产生理解**——
> 原始层内容寻址、只增不删，新解析器可**离线**重扫全部历史数据（`reparse`）。

## 这是什么

- **三个顶层专家**：直连网络 / 浏览器运行时 / 制品与媒体；线程·进程·子进程·浏览器槽位只是**执行资源**，由路由按证据与成本决定何时调用。
- **Task 是核心对象（不是 URL）**：目标 / 范围 / 预算 / **资源声明** / 证据链 / 状态；一个任务可跨多个环境。
- **路由有界**：转移上限、预算耗尽即停、失败是路由信号（重试与限流两本账分开）；每次转移都带证据、可回放。
- **Capture First**：原始层内容寻址（sha256）、原子落盘、只增不删；解析错了可以重做，事实不会丢。
- **安全**：唯一出网咽喉（SSRF 闸含逐跳复检）、凭据只走 DPAPI、日志与导出**先脱敏后落地**。

## 快速开始 · 安装

| 方式 | 做法 |
|---|---|
| 安装版 | 双击 `dist/Daedalus-Setup-<版本>.exe`——完整向导、**绝不静默安装**；许可页三语；桌面快捷方式是可选勾选项 |
| 便携版 | 直接拷贝 `dist/daedalus/`，旁边放一个空的 `portable.flag`，数据落在同级 `DaedalusData/` |

装完自证：`daedalus-cli --json doctor` —— 能不能用、缺什么、**界面语言为什么是这门语言**（`ui` 段），一条命令说清。

## 快速开始 · CLI

```bash
daedalus-cli --json collect https://example.com/     # 采集（每域限速 + robots + SSRF 闸）
daedalus-cli --json collect --dry-run https://example.com/   # 只做判定与计划；自带 network_calls=0 实测自证
daedalus-cli --json reparse                          # 用当前解析器离线重扫历史原始数据（不联网）
daedalus-cli --json export --out out.jsonl           # 导出（已脱敏）
```

子命令 10 个：`version / config / doctor / metrics / alerts / collect / reparse / export / search / ui`。
`--json` 时 stdout **只有 JSON**、编码**恒为 UTF-8**（与控制台代码页无关）；退出码 `0` 成功 / `1` 业务失败 / `2` 用法 / `3` 被拦 / `4` 内部错误。

## 界面（`daedalus-cli ui`）

- **界面语言**：设置 > 安装器选择 > 系统语言 > en-US；标题栏右侧 `English ｜ 简体中文 ｜ 日本語` 一键切换（整页重建，不留半截语言）。
- **概览**：统计卡（数字滚动）+ 运行中的资源计划 + **快速采集**——贴一行一个的目标，或**导入 TXT**（自动排除坏行、去重、按域名分组，如实回报「导入 N 条（排除 M 条无效，去重 D 条）」）。
- **任务**：双击任意一行看它的完整判断链（证据）；**重试 / 导出选中 / 删除记录**——删除先确认、只删任务与证据行，**原始捕获一个字节都不动**。
- **日志**：真实数据源，**先脱敏后显示**，上限 5000 行，分级着色。
- **外观**：底图智能取色、玻璃透明度四档预设、密度三档、动效总开关（关掉 = 立刻落终态，不是不响应）。

## 能力边界

- **做**：会话复用、Cookie 导入（限你自己的会话）、按域限速 + 抖动 + 自适应退避、被拦时降速 → 停止 → 报告并留下理由。
- **不做**：隐身注入 / 指纹伪装 / 验证码识别 / 签名伪造 / 出口轮换 / 行为拟人。
- 立场：在**用户有权访问、系统能够合法观察**的范围内尽可能完整地采集与保存数据。
