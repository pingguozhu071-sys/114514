# packaging · 跨机交付（S10 落地清单）

> 目标（机主硬要求）：**在本机打包成 EXE → 到未装过的新机器上正常安装后即可使用**。
> 三条边界（不可违背）：**不静默安装**；**缺件硬报错**；**绝不写解包临时目录**。

## 一、资产与来源（一律从单一来源读，不许硬编码）

| 内容 | 唯一来源 |
|---|---|
| 名称/版本/语言（zh-CN / ja-JP / en-US） | `src/daedalus/__init__.py`（`display_name()` / `about()`） |
| 图标 | `assets/icon.ico`（多尺寸 16…256；小尺寸是胸像，详见 `docs/13-图标与美术.md`） |
| 安装器美术 | 本目录下生成（深空渐变 `#0B0F14→#131B26` + 双光晕 + 14px 点阵 + 版本徽章） |

## 二、打包（PyInstaller）

- [ ] **one-dir 优先**（one-file 每次启动解包到临时目录：慢，且易被杀软误报）
- [ ] `--noconsole`（GUI 无控制台窗口）——这也属于机主要的"低调/不打扰"：不弹黑窗、不常驻、无遥测
- [ ] `--icon assets/icon.ico`
- [ ] **字体随包**（Roboto + LICENSE；中文用系统字体 ≥10pt，9pt 走点阵渲染发糊）
- [ ] 资源文件显式收集（QSS/SVG/字体/`assets/`），并核实**实际符号名**（不同打包器写法不同）
- [ ] **缺件硬报错**：构建期若缺 `ffmpeg`/浏览器二进制/必需资源 → **中止构建**（留一个显式逃生开关）
- [ ] 数据根规则：便携 `DAEDALUS_PORTABLE=1` → exe 同级 `DaedalusData/`；安装 → 用户目录；
      **绝不使用 `sys._MEIPASS`**（Kiana 事故：升级时删 `_internal` 把用户数据一起删光）

## 三、安装向导（NSIS，自制）

- [ ] 默认**完整向导**（语言选择 zh-CN / ja-JP / en-US，自动预选系统语言）
- [ ] `ManifestDPIAware true`（否则高分屏整窗位图拉伸、字体全糊）
- [ ] 脚本存成 **UTF-8 with BOM**；用 `python subprocess` 调 `makensis`
      （Git Bash/MSYS 会把 `/S` 这类参数改写成 `S:\` 路径）
- [ ] 安装时**先删目标子目录**（防新旧依赖混跑）
- [ ] 版本徽章**从 `src/daedalus/__init__.py` 读**
- [ ] 安装日志不含敏感信息

## 四、卸载向导（NSIS，自制；三条硬规矩来自 Kiana 三次真实事故）

- [ ] 卸载段必须带 **`un.` 前缀**（漏了 → 安装时就执行卸载逻辑，装完即被删光）
- [ ] 卸载器无法删除运行中的自己：脱手后由 **cmd 延迟扫尾**（黑窗一闪属预期，不要删这段）
- [ ] **共享资源条件化清理**（桌面/开始菜单快捷方式、注册表项），且**判断条件不能被自己的安装流程破坏**；
      三分支：① 不是登记安装 → **什么都不动**；② 是登记安装且有可恢复的原安装 → **恢复**；③ 否则彻底清理；
      分支之间**显式跳转互斥**（防"恢复完又走删除"）
- [ ] 卸载时**保留用户数据**，并在界面明确写"您的数据不会被删除"

## 五、交付前核对（发版门禁脚本化）

- [ ] 版本号**四件套一致**（配置 / 包元数据 / 程序内 / 安装脚本）
- [ ] **解包核对**：安装包内**无** cookie 文件、无主密钥、无敏感配置
- [ ] 危险操作默认 **dry-run**，且**先自证 dry-run 真的是 dry-run**（跑一次空跑，比对本机快捷方式/注册表前后一致）
- [ ] 装/卸实测在**测试账户或未安装状态**下进行（不要拿正式安装当试验田）
- [ ] **未装过的新机器**上装一次：装完即可跑（浏览器/ffmpeg 就绪探测通过）

*对应《10-完工检测清单》的 N 组条目；落地后逐条回填勾选结果。*
