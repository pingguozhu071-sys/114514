# 09 · UI 设计系统（高自由度深度定制）

> 规格来源：Kiana《暗色玻璃拟态 UI 设计系统技术报告 v2》+ `wallpaper.py` / `launcher_v8/v9`，
> 按本工程重新表述并落地。**落地位置**：`src/daedalus/ui/`（theme / wallpaper / settings / render /
> widgets / pages / app）；**美学部分在安装器里延续**（`packaging/make_installer_art.py`）。

## 一、三层材质（不可省）

| 层 | 做什么 | 落地 |
|---|---|---|
| ① 底图层 | 用户图（可关 → 回退主题纯色） | `ui/wallpaper.py` + `WallpaperWidget` |
| ② **玻璃层** | 卡片/面板：竖向渐变 + 1px 中性描边 + 12px 圆角；透明度由**单一参数** `panel_alpha` 控制 | `ui/theme.py` 的 `panel_qss()` / `card_qss()` |
| ③ 控件层 | Fluent 组件库（`qfluentwidgets`），**不逐控件自定义样式** | `ui/widgets.py` |

玻璃层的作用是**可读性基础设施**：把底图局部对比度压到统一范围，控件才有稳定的对比度基线。

**两条铁律**：
- **同页所有卡片由同一个函数生成**（`panel_qss`）；专家模式（单卡覆写）**未实现**，
  因此设置界面里也不暴露那个开关（假开关比没有更坏）；
- **描边固定**：深 `rgba(255,255,255,22)` / 浅 `rgba(0,0,0,14)`，**不随 alpha 变**
  （描边是「卡片边界」的语义，不是装饰；跟着 alpha 变会让边界在高透明时消失）。

**玻璃色值（照 Kiana 的冷灰，2026-09-23 修正）**：
深色 `rgba(30,37,46,235·a) → rgba(18,23,30,185·a)`、浅色 `rgba(255,255,255,242·a) → 220·a`。
两个要点：① **上实下透**（顶实底透才有体积感）；② 明暗两边**同一色相族**（冷灰）。
原来的写法是「白纱 → 纯黑」，卡片上半发灰白、下半发黑，又脏又没有体积感——这是「美术像屎」的一部分。
用**乘法**（而不是区间映射）保住 235:185 的比例，任何 alpha 下立体感都不变。
悬停时只把渐变与描边**提亮 1–6/255**（`panel_qss(..., hover=0..1)`），alpha 不动。

**强调色克制**：强调色只用于「当前位置（导航选中）/ 开关开启 / 每页一个主按钮 / 进度 / 取色联动 / 签名」；
**卡片描边与统计数字都不用强调色**（一屏内强调色面积 <5%，否则重点会消失）。

## 二、可定制的面（全部**即改即存**，没有"应用"按钮）

| 组 | 可调项 | 落地 |
|---|---|---|
| 主题 | 深/浅（默认深） | `Tokens.light` |
| 强调色 | 4 档 `#4FA3E8/#9B7EDE/#2FC6C6/#F0708A` + **自动取色** + **锁定开关** | `theme.ACCENT_PRESETS`、`wallpaper.extract_accent` |
| 玻璃 | 透明度滑杆 40–95（默认 65）+ 四档预设（通透 40/标准 65/柔和 78/实心 95） | `settings.FACTORY_PRESETS` |
| 底图 | 单图/文件夹轮换/随机；模糊 0–30（核 `k=2b+1`）；蒙层 0–60（**手动只能加暗**）；九宫格焦点；下采样长边 2560 | `wallpaper.process_wallpaper` |
| 排版 | 界面字号档（**中文 ≥10pt**，9pt 走点阵渲染发糊）；日志等宽字体 | `Tokens.font_pt` |
| 密度 | 紧凑/标准/宽松（标准 = 外边距 28、卡片间距 14、卡内 18/14、卡内间距 4/10/12） | `Tokens.spacing()` |
| 动效 | 总开关 + 版本/悬停/滚动时长 + 限帧；渲染防抖 250ms（见第五节动效清单） | `Tokens.anim_ms()/hover_ms()/roll_ms()/frame_min_ms()` |
| 预设 | 命名保存/加载/**导入导出 JSON** | `settings.SettingsStore` |

**状态色不参与强调色联动**（语义色必须稳定）：`theme.status_colors()` 独立于 `accent`。

### 自动取色的规则（写死，可复核）

缩到取样尺寸（**最近邻**，要真实像素色）→ HSV 过滤（`S>60 且 V>40`，滤掉灰与死黑）→
每通道 `//32` 量化 → 直方图众数 → **可读性钳制**（`S ≤ 0.9`，`V ∈ [0.45, 0.85]`，色相不动）。

- 整张图太灰 → **如实回退**默认色并说明原因（不假装取到了颜色）；
- **锁定**时原样使用用户选的颜色（那是明确选择，所见即所得；钳制只用于机器算出来的颜色）；
- **同色去重**：颜色没变就不重算、不重绘。

## 三、图像管线六步（一步都不能省）

| 步 | 做什么 | 为什么（踩过的坑） |
|---|---|---|
| ① | `np.fromfile` + `cv2.imdecode` | `cv2.imread` 在**中文路径**下静默返回 None（"底图设了没反应"且无报错） |
| ② | 长边 > 2560 → `INTER_AREA` 下采样 | 防 8K 图爆内存 |
| ③ | cover 裁切 + **九宫格焦点** | **绝不非等比拉伸**（人像会变形） |
| ④ | 高斯模糊（核 `k = 2b+1`） | 偶数核会偏半像素 |
| ⑤ | 智能蒙层：`max(手动, 自动)`，自动 = `clamp((亮度均值-128)*0.35+20, 8, 45)%` | 手动只能**加暗**；否则白字会糊在白底上 |
| ⑥ | 转 `QImage` **必须 `.copy()`** | 否则指向 numpy 临时缓冲 → 野指针花屏 |

## 四、性能红线与手法（`tools/perf_probe.py` 实测）

| 红线 | 实测（offscreen） | 手法 |
|---|---|---|
| 停顿 < 200ms | **4.8ms** | 防抖 250ms + 忙时挂起不丢请求 + **代数号守卫**（过期结果丢弃）+ `postEvent` 投递 |
| 切页 < 400ms | **1.1ms** | 页面懒建 + 控件树只建一次 |
| 最大化重排 < 1200ms | **4.3ms** | 尺寸不符时**裁切而非整幅重采样**；`QPixmap` 只在主线程转 |
| 图像管线单次 < 200MB | **182MB**（8K 源） | 解码后立刻下采样；峰值随**源图分辨率**线性增长（这条已写进探针输出） |

配套手法：渲染调度 = 防抖 + 忙时挂起 + 代数号守卫 + `postEvent` + `QPixmap` 仅主线程；
取色**同色去重**（Kiana 实测把最大停顿 7602ms → 0ms）。

## 五、布局与组件

- **骨架 = 组件库的 `FluentWindow`**（2026-09-23 换的，理由见下方「骨架变更」）；
  它自带 **48px 标题栏**、**可折叠导航**（150ms 展开动画）、**切页 300ms 淡入淡出**、
  全控件悬停 120ms 过渡——这些"动向"是自绘骨架给不了的；
- 左侧导航：功能项在上、**设置固定最下面**（`NavigationItemPosition.BOTTOM`，后加的在上，
  所以先加「关于」再加「设置」）；导航**启动即展开**（`setExpandWidth(312)` + `expand(useAni=False)`）；
- 页面顶部 = **`TitleLabel` 页面标题 + 一行 12px 灰副标题**（`PageBase.subtitle()`）；
  那一行的作用见 Kiana 的原话：「破掉一上来就是卡的拥挤感」；
- 页面基类 = `QScrollArea` + **透明皮肤三件套**：QSS 用 `objectName` 限定 /
  `setAutoFillBackground(False)` 在 `setWidget()` **前后各调一次** / 卡片样式由同一函数生成；
  页面边距 **28/28/28/20**（下边距更小：滚到底不留一大块空白）；
- 卡片：间距 **14** > 卡内最大 **12**（格式塔接近性）；卡内 `(18,14)`、卡内间距 4/10/12；
- 统计卡：数字 **26px/700 在上**、灰色标签在下；数字用**主题文字色**（不是强调色）；
- 窗口最小 **980×620**、启动 **1360×860**；
- 右下角签名（可关，颜色随强调色，`Show/Resize/Activate` 时 `raise_()`）。

### 骨架变更（为什么把自绘的换掉）

原来是自己画的标题栏 + 玻璃卡片导航。**那套的"硬"不是审美问题，是机制问题**：
自绘骨架没有任何动效（切页硬切、导航硬切、悬停硬切），而库的 `FluentWindow` 白送
导航展开 150ms、切页 300ms（InQuad）、全控件悬停 120ms——正是设计系统报告里那句
「其余交给 Fluent 组件库」的落点。代价：自绘标题栏/签名锚点那套代码删掉，
`TitleBar` 类不再存在，签名靠 `Show/Resize/Activate` 重新定位。

### 动效清单（全部受 `animations` 总开关控制）

| 动效 | 时长 / 曲线 | 实现 | 关掉总开关时 |
|---|---|---|---|
| 底图交叉溶解 | **450ms / OutCubic / 限帧 30fps** | `WallpaperWidget.set_image` + `paintEvent` 双绘（旧图 `setOpacity(1-fade)`） | 直接落图，不溶解 |
| 卡片悬停 | **120ms / OutCubic** | `QVariantAnimation` 插值 0→1，每帧重生成**这一张卡**的 QSS | 立刻到终态（仍有悬停反馈） |
| 统计数字滚动 | **360ms / OutCubic / 限帧** | `QVariantAnimation` + 从旧值滚到新值（小数位沿用目标文案） | 一步到位 setText |
| 页面切换 | **300ms（库）/ InQuad** | 库的 `PopUpAniStackedWidget` | 库内部行为 |
| 导航展开 | **150ms（库）** | 库的 `expandAni` | 库内部行为 |

**语义约定**：`animations=False` 不是"不响应交互"，而是"不做过渡、立刻到终态"——
门禁 S10-E9 就是按这条语义断言的（关掉后悬停/滚动/溶解都必须**立刻落值**）。

## 六、安装器美术（同一设计语言的延伸）

深空渐变 `#0B0F14→#131B26` + 双光晕（GaussianBlur + screen 叠加）+ 14px 点阵（极低 alpha）+
Logo 芯片（圆角 + 外发光）+ **版本徽章从版本单一来源读** + 2px 底部渐隐强调线。
两种情绪：安装页"产品能力"、卸载页"语义化说明（您的数据不会被删除）"。

> 文案走"二次元傲娇"（安装向导与界面提示），但**技术事实一律直说**：
> 缺什么、被谁拦、为什么，不用撒娇的语气掩盖。

## 七、明确不做（保持"设计系统"而不是"自由乱涂"）

霓虹/赛博风、拟物折射/焦散、重动效、逐控件自定义样式。

## 八、自测清单（门禁 `s10_gate.py` 的 A–E 五组）

| 组 | 检查 |
|---|---|
| 视觉 | 层级与分组感；四档强调色；渐变质感；语义色不随强调色；字号下限；密度不破 |
| 底图 | 中文路径可读；竖/横/方图无变形；纯白与纯黑图文字仍可读（自动蒙层）；手动暗化拉到 0 时亮图仍有自动保护 |
| 交互性能 | 拖窗跟手；快速连换图显示最后一张（代数号）；切页 <400ms；主题即切即生效；外观参数重启保持 |
| 边界 | 底图损坏/被删回退纯色不崩；8K 图不爆内存；设置文件损坏回退且说明原因；预设导入导出往返 |
| **接线**（E 组） | 设置**真的**驱动界面（不是只存盘）；底图管线与自动取色有触发点；显式选色不被自动覆盖；语言切换整页重建；语言解析顺序（见下） |

## 九、接线：设置 → 界面（**这一节的由来是"组件全对、接线全没接"**）

原来 S10 的 UI 用例直接调 `set_wallpaper()` 这类**组件方法**验收，于是"设置里存了底图、
界面从不加载"这种 bug 一路假绿到打包。现在门禁一律走**真实信号路径**：

```
改控件 → 控件信号（如 editingFinished）→ SettingsStore 存盘 → ctx 通知 → MainWindow 处理 → 样式/底图/取色更新
```

- `MainWindow.wire_context(win, store, ctx)` 是**唯一**接线点，`build_headless()`（测试/无头）与
  `run_ui()`（真跑）**共用**它——两条路径各写一套就是 B18-1 那种"其中一条从来没接"。
- 处理器按**变更的键**分流：`wallpaper/blur/dim_manual/focus/downsample_max` → 重跑底图管线；
  `accent/accent_locked` → 按规则决定是否自动取色；其余 → 只重刷样式。
- 门禁读 `win._ui["applied"]`（**真的进了样式的那份值**），而不是读落盘值——
  落盘对不代表生效，这正是 B18-6 的教训。

### 数据刷新：指标轮询（第三个接线缺口）

`refresh_pages()` 曾经**写了但没有任何调用者**——四张统计卡永远停在占位符「—」、任务表永远空。
现在由 `MainWindow.start_metrics_poll()` 接上：**1 秒一拉**（`ctx.refresh()` → `refresh_pages`），
启动时先拉一次（别让用户先看一秒占位符）。

- 代价控制：一次拉包含 `tasks_overview(limit=50)`（一次读库）。所以记录 `last_ms/max_ms/slow/errors`，
  **单次 > 250ms 自动降频到 5 秒**并记日志——宁可少刷，不许卡手（与"停顿 <200ms"同源）。
- 数据都从 `ctx` 走（页面与窗口**都不直连引擎**）；读数失败**不静默**（计入 `errors`）。
- 门禁 S10-E8：既断言"存在调用者"，也真拉一次、断言占位符变成真数字（实测 0.4–2.3ms）。

## 十、多语言（界面语言**跟随本机**，不是跟随开发机）

**解析顺序（前者赢）**：`设置里的显式选择` → `安装器写的 install.marker` → `系统 UI 语言` → `en-US`。

| 环节 | 落地 |
|---|---|
| 系统语言 | `GetUserDefaultUILanguage` + LCID 映射（2052→zh-CN、1041→ja-JP、1033→en-US、1028→zh-TW…） |
| 安装器选择 | NSIS 把 `$LANGUAGE` 写进 `install.marker` 的 `lang=`；**冻结态找 exe 同级**（不是 cwd、不是解包临时目录） |
| 自证 | `cli doctor --json` 输出 `ui` 段：`{locale, source, setting, installer, system}`——装机后随时可查"为什么是这门语言" |
| 文案 | `ui/i18n.py` 单一表（80 键 × 3 语言）；`ui/` 其余文件**零硬编码可视中文**（门禁扫 AST 字符串字面量） |
| 切换 | `apply_locale()` = **整页重建**（文案是建控件时写死的，重刷样式刷不掉旧文案） |

三条硬规矩：
1. **绝不出现"选了简体却蹦日文"**：安装器选择**一定**优先于系统语言，且用户设置**一定**优先于两者；
2. 缺键**不静默**（`Translator.missing` 记账，门禁断言每种语言都能无缺键取一遍）；
3. 中文标点用 `「」`（半角引号在中文串里既难看又会截断字符串）。

> 反例备忘：`--json` 的输出编码**恒为 UTF-8**，与控制台码页无关（机器读的契约）；
> 人类可读输出则跟随码页并 `errors="replace"`，保证在 GBK 的 cmd 里也不崩。
