# 12 · 命名与本地化（唯一来源）

## 一、名称

| 项 | 值 |
|---|---|
| **名称（en-US）** | **Daedalus** |
| 中文 | **代达罗斯** |
| 日本語 | **ダイダロス** |
| 包名 / 工程目录 | `daedalus` |
| CLI 名（预留） | `dae` |
| 安装包名（预留） | `Daedalus Setup` |

**怎么来的**（你要的是"精致"，不是"经过"）：Daedalus 是希腊神话里的匠人，他的名字在英语里直接生出形容词
**daedal**：*精工细作的、精巧的、错综复杂的*。整段神话与本工程一一对应：

| 神话元素 | 对应本工程 |
|---|---|
| 迷宫 | 多种架构并存的多路径系统（复杂但不迷失） |
| 阿里阿德涅之线 | 血缘与可重放——顺着线永远能退出来 → **事实不会丢** |
| 翅膀（飞太高蜡会化） | 能力有边界 → **不越界、不突破对方防护** |

**备选（你原本想的）**：**Odysseus / 奥德修斯 / オデュッセウス**——绰号 *polytropos* 意为"多面多谋"，
也贴"多种架构"，但 *Odyssey* 确实带"旅程/经过"那层意思，所以主选 Daedalus。

## 二、语言（固定三种，不硬编码）

| 语言 | 标签 | 拼写 | 说明 |
|---|---|---|---|
| 简体中文 | `zh-CN` | 代达罗斯 | |
| 日本語 | `ja-JP` | ダイダロス | 片假名转写 |
| English | `en-US` | Daedalus | **en-US 拼写**（不用 en-GB；`localisation`/`colour` 这类拼法一律不出现） |

**唯一来源**：`src/daedalus/__init__.py` 里的 `NAME_EN / NAME_ZH / NAME_JA / LOCALES / VERSION`
与 `display_name(locale)` / `about()`。**任何地方都不许再写死名字或版本**：
CLI 帮助、GUI 标题与关于页、安装向导文案与美术、CHANGELOG、包元数据一律从此读取
（Kiana 的教训：版本四件套漏一个就发版失败 → 用脚本校验一致性）。

## 三、命名规则（给后来者）

1. **新文件命名**：包内模块用小写+下划线；**机制件**与**组装件**分开
   （例：`core/rate_limiter.py` 是机制，`core/policy.py` 是策略组装；`env/resumable.py` 是机制，
   `env/media.py` 是环境组装）。
2. **术语固定**（中英对照，代码与文档同用）：
   采集环境 = acquisition environment；执行资源 = execution resource；适配器 = adapter；
   织物 = fabric；证据 = evidence；捕获面 = capture；理解面 = understanding；
   原始层 = raw layer；派生层 = derived layer。
3. **禁止**：在字符串里拼语言（`"共 " + n + " 项"`）；在代码里写中文文案（文案属于资源层）。
4. **改名流程**：只改 `src/daedalus/__init__.py` + 目录名 + 包元数据，然后跑
   `packaging/version_check`（S10 落地）与 `tests/gates/contract_selftest.py`。
