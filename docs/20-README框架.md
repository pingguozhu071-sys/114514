## 0. 语言切换行（照机主给的图）

每份 README 的**第一行**必须是语言切换链接条，样式照图：`English | 简体中文 | 日本語`。

```
[English](README.en-US.md) | 简体中文 | [日本語](README.ja-JP.md)
```

* 规则：**当前语言不可点**（纯文本，不加链接），其余两个是可点的链接；分隔符用 `|`；
* 语言名用**各自母语原文**（简体中文 / 日本語 / English），不做翻译；
* 每份文件里这三行的写法只有"哪个是纯文本"不同，其余逐字相同——这样三份文件互相导流不会漏。

## 2. 这是什么（5 条要点，每条 ≤2 行）

1. **三个顶层专家**：直连网络 / 浏览器运行时 / 制品与媒体；线程·进程·子进程·浏览器槽位只是**执行资源**，
   由路由按证据与成本决定何时调用（来源 `docs/00`、`docs/01`）。
2. **Task 是核心对象（不是 URL）**：目标 / 范围 / 预算 / **资源声明** / 证据链 / 状态；一个任务可跨多个环境。
3. **路由有界**：转移上限、预算耗尽即停、L0→L5 便宜先行、**失败是路由信号**（退避 ≠ 重试，两本账）。
4. **Capture First**：原始层内容寻址、只增不删；新解析器可**离线**重扫全部历史（`reparse`，不联网、自证 0 次网络调用）。
5. **安全与边界**：唯一出网咽喉（SSRF 闸含逐跳复检）、凭据只走 DPAPI、日志与导出**先脱敏后落地**。

## 4. 快速开始 · CLI

* **10 个子命令**（来源 `src/daedalus/cli.py` 的 `build_parser`）：
  `version` / `config` / `doctor` / `metrics` / `alerts` / `collect` / `reparse` / `export` / `search` / `ui`
* **输出契约**：`--json` 时 stdout **只有 JSON**、编码**恒为 UTF-8**（与控制台代码页无关）；人话走 stderr。
* **退出码**：`0` 成功 / `1` 业务失败（如被拦） / `2` 用法错 / `3` 策略拒绝 / `4` 内部错误。
* 示例三条（正文里给可直接复制的命令）：
  ```bash
  daedalus-cli --json collect https://example.com/
  daedalus-cli --json reparse          # 离线重扫历史原始数据
  daedalus-cli --json export --out out.jsonl   # 导出（已脱敏）
  ```

## 6. TXT 链接导入（机主点名功能，单独一节）

* **用法**：概览页「快速采集」卡 → 「导入 TXT」→ 选一个 `.txt` → 文本框被填成**一行一个 URL** → 按「开始采集」。
* **行为细节**（正文要写全，用户才知道它有多聪明）：
  * 只收 `*.txt`；
  * 编码自动识别（BOM / UTF-8 / GBK）；
  * 每行取**第一个** `http(s)://` 记号，容忍「1. 链接 标题」这类前后缀，剥掉行尾标点；
  * **坏行被排除**（不是静默丢弃）：scheme 不是 http(s)、域名空、含空白等；
  * **去重**（保持首次出现顺序）；**按域名分组**（组间空行）；
  * 汇总如实回报：「导入 N 条（排除 M 条无效，去重 D 条），K 个域名」。
* 来源：`src/daedalus/ui/pages.py` 的 `_quick_collect`；门禁 `tests/gates/s10_gate.py` 的 TXT 导入用例。

## 7. 能力边界（做 / 不做）

* **做**：会话复用、Cookie 导入（仅你自己的会话）、按域限速 + 抖动 + 自适应退避、
  逐跳 SSRF 复检、被拦时**分级退避 → 降速 → 停止 → 报告并留下理由**。
* **不做**：隐身注入 / 指纹伪装 / 验证码识别 / 签名伪造 / 出口轮换 / 行为拟人。
* **立场原话**（`写作.txt` 末节）：「在用户有权访问、系统能够合法观察且资源允许的范围内尽可能完整地采集与保存数据」。

## 8. 架构一屏图（ASCII，正文里给）

```
人机工具（CLI / GUI）
   → Task（目标·范围·预算·资源声明·证据链）
      → 证据驱动路由（有界 · 可解释 · 便宜先行 L0→L5）
         → ① 直连网络   ② 浏览器运行时   ③ 制品与媒体
            → 执行织物（线程 / 进程 / 子进程 / 浏览器槽位）
               → 捕获面（内容寻址，只增不删）
                  → 理解面（探测 → 解析 → 归一 → 校验 → 去重）
                     → 存储面（原始 blob / 元数据 SQLite+FTS5 / 变更台账 JSONL）
   织物：发现 · 理解 · 存储 ＋ 资源仲裁 ＋ 观测（p50/p95/p99）
```

## 9. 开发者：校验与构建

* `python tools/gates.py` —— **12 道门禁 · N 项**（N 待填实测值；以**退出码**为准）。
* `python tools/ui_walk.py` —— 界面实操走查 **M 项**（逐页进入、每个控件走真实信号、三张特征图取色、
  间距规格、语言不混、任务页三操作、TXT 导入）。
* `python tools/lint.py` —— 静态纪律扫描：**硬拦 0**；软提示有基线，**不许上升**。
* `python tools/icon_check.py` —— 图标/横幅**颜色契约**（原画 ↔ 抠图 ↔ 各尺寸 ↔ 安装器美术同色向）。
* `python tools/build.py` —— 打包（PyInstaller + NSIS），含**产物核对硬断言**（缺件中止、无敏感文件）。
* 纪律：**一修复 = 一 commit = 一组回归测试**；未完成项登记 `docs/PENDING.md`，不假装完成。

## 12. 发布到远端仓库时的三条硬规矩

1. **不删远端已存在的 `LICENSE`**（MIT，Copyright 行原样保留）；
2. 远端根目录 `README.md` 是初始化占位——发布时**改成一行指向 `README.zh-CN.md` 的链接**，

   一律不入库（`.gitignore` 已覆盖，推送前用 `git status` 复核一遍）。

## 13. 翻译原则（en / ja 两份）

* zh 是权威源；en/ja **逐节同构**（同一节号、同一顺序、同样给命令与数字）；
* 术语保留英文原样：`Capture First` / `reparse` / `doctor` / `SSRF` / `DPAPI` / `FTS5`；
* 语言名用母语原文；三份文件里的**数字必须一致**（同一写作时点实测）；
* 不逐字硬译中文长句——按各自语言的习惯重写，但**事实、数字、命令一个字都不许变**。
