# 01 · 采集类型分类学（四档归位）

> 这份文档回答一个问题：**"某种采集需求，在这台引擎里归到哪儿？"**
> 答案只有四档：**环境**（3 个）/ **执行资源** / **适配器** / **织物**。
> 判据是"它在系统里承担什么角色"，不是"它用了什么库"。

## 一、采集环境（只允许 3 个；加环境需评审，默认拒绝）

| 环境 | 承担什么 | 落地 | 资源账本 |
|---|---|---|---|
| ① **直连网络** | 直接取流（HTTP/API/JSON/RSS/Sitemap/静态文件） | `env/net.py`；出网一律经 `net/fetch.py` | `network` 槽位 |
| ② **浏览器运行时** | 真的执行页面（脚本渲染、XHR、DOM）并**观察网络活动** | `env/browser.py` | `browser_contexts` / `browser_pages`（**默认 0**） |
| ③ **制品与媒体** | 大对象、分片流、文档、可播放媒体：下载 + 契约验证 | `env/media.py`、`adapters/hls.py` | `subprocess` + `disk` |

**判断依据（证据，不是猜测）**：

| 现象 | 归属 |
|---|---|
| 直连拿到可用内容（`ok`） | ① 结束 |
| 直连拿到空壳/质量不足（`empty_content`） | → ② 浏览器 |
| 声明 HLS/DASH（`media_manifest`） | → ③ 制品与媒体（协议适配器） |
| 大对象 / 未知二进制（`large_object`） | → ③（会话内下载 + 契约） |
| SSE / WebSocket（`stream`） | 协议适配器（**V0.1 未启用**，记候选） |
| 404/410（`permanent_failure`） | 死信（不重试） |
| robots/SSRF 拒绝（`policy_denied`） | 终态拒绝（**零出网**） |

## 二、执行资源（架构不固定，资源由任务声明）

| 资源 | 什么时候用 | 落地 | 默认容量 |
|---|---|---|---|
| 线程池 | 并发取流/解析（IO 与轻 CPU） | `exec/pools.py` | 下载 128 / 解析 20 |
| 进程池 | CPU 密集且不可信（文档/媒体元数据解析） | `understand/parsers/mediainfo.py` 的 `run_isolated` | 12 |
| 子进程 | 外部工具（ffmpeg/ffprobe） | `exec/subprocess.py` | 4 |
| 分片并发 | HLS 分片（**拼接顺序由序号决定**） | `adapters/hls.py` | 4 |
| 浏览器槽位 | 进程/上下文/页三层，最稀缺 | `env/browser.py` | **0（不启用）** |
| 异步事件循环 | 长连接高并发那一格 | `core/registry.py` 的 `async` | **0（刻意留着）** |

三条规矩：
1. **容量显式**（来自资源计划，不看机器性能自动调）；
2. **声明缺省即拒绝**（任务不申明就不给，`core/registry.py`）；
3. **同一份共享状态不得被两种执行模型直接操作**（写库只有单写线程）。

## 三、适配器（加一个来源 = 加一个文件）

| 类型 | 落地 | 说明 |
|---|---|---|
| Sitemap / RSS·Atom | `understand/parsers/feed.py` | 订阅天然"一批条目"，一条一份派生记录 |
| GraphQL / JSON API | `understand/parsers/datafile.py`（JSON）+ 直连环境 | 需要认证的走会话 jar |
| HLS / DASH | `adapters/hls.py` | AES-128-CBC（协议强制）+ 显式 IV 或按序号推导 |
| 站点专用提取器 | `adapters/extractors/<site>.py`（注册表 + 兜底） | `match(url, evidence)` + `extract(raw)` |
| 文档/媒体元数据 | `understand/parsers/mediainfo.py` | 图片尺寸/容器条目/ffprobe/PDF 粗计 |
| robots 语法 | `net/robots.py` | RFC 9309 语义 |
| 条件请求 | `net/cache.py` | ETag/Last-Modified；304 → 复用旧内容 |

## 四、织物（Fabric：不是专家，是所有环境共享的底座）

| 织物 | 落地 |
|---|---|
| 任务与前沿 | `frontier/frontier.py`（租约/CAS/心跳/看门狗/批量/死信） |
| 证据路由 | `core/router.py` + `core/evidence.py` |
| 去重与增量 | `frontier/dedup.py` + `frontier/urlcanon.py` + `understand/ledger.py` |
| 捕获与重放 | `capture/rawstore.py` + `capture/index.py` + `capture/replay.py` |
| 资源仲裁 | `core/registry.py` + `core/limits.py` + `exec/pools.py` |
| 三层存储 | `raw_data/` + SQLite（WAL/单写/批提交）+ JSONL |
| 观测 | `obs/metrics.py` · `obs/logs.py` · `obs/alerts.py` · `obs/drilldown.py` |
| 安全与合规 | `net/ssrf_gate.py` · `obs/policy.py` · `privacy/*` |
| 环境选择 | `core/router.py`（唯一一处决定"用哪个环境"） |

## 五、按"数据形态"归位（速查）

| 你要采的东西 | 环境 | 执行资源 | 备注 |
|---|---|---|---|
| 博客/新闻页 | ① 直连（失败→② 浏览器） | 线程池 | 正文抽取 + quality 闸 |
| JSON API | ① 直连 | 线程池 | 会话/Cookie 复用在咽喉层 |
| 需要登录的页面 | ① 直连（**你已有权访问的会话**） | 线程池 | 不做账号池、不做绕过 |
| SPA（脚本渲染） | ② 浏览器 | 浏览器槽位 | 观察到的 XHR 载荷落原始层 |
| 图片/PDF/Office | ① 直连（小）或 ③ 制品（大） | 进程池（解析隔离） | 契约验证（大小/格式/哈希） |
| 视频流（m3u8） | ③ 制品与媒体 | 子进程（ffmpeg）+ 分片并发 | 解密分片按序号拼装 |
| Sitemap/订阅 | ① 直连 | 线程池 | 一条目一记录 |
| SSE/WS 长连接 | 协议适配器（**未启用**） | 异步那一格 | 记候选并说明 |

## 六、分类学要守的边界

- **不新增环境**：三个够了。新需求优先落在"适配器"或"执行资源"上。
  真要加环境，必须同时具备：独立资源账本、独立生命周期、**自己的取流闸**、独立预算科目——
  并写进 `core/registry.py` 与 `docs/02` 的不变量表。
- **不把库当分类**：`asyncio`/`aiohttp` 不是"一种采集环境"，它们是**执行资源**的实现方式。
- **不把站点当架构**：某站的专用逻辑属于适配器，永远不进核心。
