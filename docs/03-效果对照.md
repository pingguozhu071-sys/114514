# 03 · 效果对照（对着三篇原始文档逐条核）

> 判据来源：`Executive Summar.txt`（规矩与门槛）、`可以.txt`（能力与第一性原则）、

> 本表只写**已落地**的东西，并给出门禁编号或文件位置。**没做的不写成做了**（见 `PENDING.md`）。

## 一、对着 `写作.txt`（最终裁决）核

| 要求 | 落地 | 证据 |
|---|---|---|
| **专家只有三个**（直连网络/浏览器运行时/制品与媒体） | `env/net.py` · `env/browser.py` · `env/media.py`；`core/router.py` 的 `STAGE_ENV` 只映射这三个 | `docs/02` 转移表；S6/S8 |
| **Task 是核心对象，不是 URL** | `core/task.py`（kind/target/goal/scope/policy/resources/budget/evidence/幂等键/parent） | S2（幂等键）、S6（子任务血缘） |
| **Router 不神化**：证据驱动、有界、可解释 | `core/router.py`：每次转移返回带 `reason` 的 `Decision`，落进证据链 | S6（J 用例：字段齐全可回放） |
| **便宜先行**（L0→L5） | `router.start()` 直接给 DIRECT；只有证据要求才升级 | S6（B/C 用例） |
| **Capture First 是地基** | `runner._do_direct`：先 `store.put` 再解析；**CAS 保护的是状态与派生行**，原始层内容寻址幂等 | S3/S6（A2/H 用例） |
| **Discovery/Parser/Storage 是织物不是专家** | `capture/discovery.py` · `understand/registry.py` · `store/*` 都不参与路由 | S3/S4 |
| **资源由任务声明、Governor 仲裁** | `core/task.py` 的 `ResourceRequest` + `core/registry.py`（缺省即拒绝）+ `core/limits.py`（内存自证） | S4/S7（E10 用例） |
| **顶层只留 Task/Policy/Evidence/Route/Resource/Artifact/State** | `docs/00` 的七行表，每行都有落地位置 | 本文件 |
| **有界转移**（每任务有转移上限+预算） | `core/budget.py`（5 维）+ `Router.max_transitions` | S6（G 用例） |
| **失败是路由信号**（不是"该上对抗了"） | `evidence.py` 的信号表；`policy_denied` 直接收口 | S6（D/E/F） |

## 二、对着 `可以.txt`（能力与第一性原则）核

| 要求 | 落地 | 证据 |
|---|---|---|
| 通用数据采集与感知引擎（**不叫 Crawler**） | 名字 `Daedalus`；包名 `daedalus`；CLI 描述"统一采集与感知引擎" | `src/daedalus/__init__.py` |
| **永远不丢原始数据** | 内容寻址原始层 + 每记录 gzip；解析失败 `keep_raw`；`daedalus reparse` 离线重扫 | S3（A1–A5）、S9（D1：网络增量 0） |
| 双层数据（Raw Truth / Derived Intelligence） | `raw_data/` 与 `pages`/派生记录分离；重放可重建派生层 | S3 |
| Scheduler 当大脑、线程模型不固定 | `frontier` + `route` + 资源注册表；线程/进程只是资源 | `docs/01` |
| **一个任务可跨多个执行范式** | S6 C 用例：`direct → artifact` 走完；S8 E1：`direct → browser → done` | S6/S8 |
| 持久工作流事件历史 | `task_evidence` 表（每条证据落库）+ `tasks.transitions` | S6（J） |
| 存储三分 | 原始 blob / SQLite 元数据 / JSONL 分析 | `docs/00` |
| **失败不是失败，是路由信号** | 见 `docs/02` 信号表 | S6 |
| 只在有权访问且能合法观察的范围内 | `docs/07`；`policy_denied` 是终态；不做对抗 | S8（D1）、S10（D6） |

## 五、与"效果"有关的三个数字（可复现）

| 指标 | 数值 | 怎么复现 |
|---|---|---|
| 离线合成闭环吞吐 | **约 132–177 页/秒**（8 线程，24KB 页面，无网络延迟） | `python tools/bench.py --tasks 300 --size 24576 -w 8` |
| 长跑稳定性 | 5 分钟 39,600 任务：**跑丢 0 行**、内存回归后零增长、句柄不涨 | `python tools/soak.py --minutes 5` |
| 界面性能红线 | 停顿 4.8ms / 切页 1.1ms / 重排 4.3ms / 8K 底图峰值 182MB | `python tools/perf_probe.py` |

> 这些数字是**离线合成负载**（假咽喉、真闭环）：测的是引擎自身开销，不是目标站吞吐。
> 真实吞吐由网络与目标站决定。
