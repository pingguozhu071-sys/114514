## 三、生成管线（`tools/make_icon.py`）

```bash
python tools/make_icon.py                 # auto → rembg/isnet-anime（推荐）
python tools/make_icon.py --engine cv2    # 自研管线（无 rembg 时的回退）
python tools/make_icon.py --draw-rect     # 只在原图上画出胸像比例框（改比例框时先跑这个）
```

管线四步：
1. **抠图**：`rembg` + `isnet-anime`（专为动漫立绘训练的 onnx 模型；首次运行自动下载 ≈176MB 到 `~/.rembg/`）。
2. **统一收尾**：闭运算 → **填洞**（白衬衫/脸这类内部区域必须实心）→ 保留够大的连通域 → 腐蚀 1px → 高斯羽化 + smoothstep。
3. **合成**：预乘 alpha 缩放（否则缩小时透明边缘发黑/发白）；全身与胸像各出一套；可加深色圆角底。
4. **写 ICO**：手写容器，每个尺寸单独重采样并内嵌 PNG（16/24/32/48/64/128/256）。

## 四、踩坑记录（13 版迭代浓缩，写给下一个改这个脚本的人）

1. **`cv2.imwrite` 在含中文的路径下静默失败**（返回 False、不抛异常、文件不出现）。本工具第一版就中了：
   `assets/` 路径里有中文，四张 PNG 一张都没写出来，而 ICO 写成了（那是 Python 自己的文件 I/O）。
   → 用 `imencode` + `Path.write_bytes`（工具里的 `imwrite_u`）。
2. **非预乘 RGBA 缩放会产生"面纱/发灰"假象**：透明像素的 (0,0,0) 会被混进颜色。核对用图必须走预乘路径，
   否则你会去修一个根本不存在的 bug（我修了三轮）。
3. **不要在 rembg 的结果上再叠"按颜色剔背景"的规则**——这是最贵的一课：
   立绘里**皮肤与白衣服也是浅色、且与背景接壤**，"浅色可达泛洪"会把**脸和衬衫一起吃掉**，
   表现为"头部碎成几块"。正确做法：**信模型**，背景设计层（水印/框线）用**裁剪规避**或后续手工修。
4. **纯规则分割（cv2 路线）在这张图上不可行**：它有"整片浅灰渐变背景 + 构图框线 + 青色网格 + 中性灰水印 + 柔和投影"，
   颜色/形态学判据总会顾此失彼（试过 4 版：吃背景 65% → 打碎主体 → 吃脸）。
   保留 `--engine cv2` 只是"没有 rembg 时的回退"，**不要指望它出高质量结果**。
5. **改比例框要画出来核对**：只在 256px 缩略图上肉眼估位置，会把"手臂"当"头"（真的搞错过）。
   用 `--draw-rect` 出带 10% 网格的核对图，一次改对。
6. **模型下载可能被掐断**：`birefnet-*`（更下一代模型）在 GitHub Release 下载时两次 `RemoteDisconnected`。
   如果以后网络好，值得重试——BiRefNet 对"设计层背景"的处理明显更强。

## 五、已知残留（诚实记录）

这张立绘的背景上有**原画自带的设计层**：`VOCALOID 02`、`01`、构图框线、青色网格、标注文字、柔和投影。
`isnet-anime` 会把它们**部分保留**（模型把它们当成了前景物体）。

- **对图标无影响**：图标的小尺寸（16–48）用胸像裁剪，该区域残留极少；再小到 16px 完全不可见。
- **要"纯角色、零残留"的透明 PNG**：三条路
  ① 换 `birefnet-general`（网络好时重试，见踩坑 6）；
  ② 手工修掩膜：导出 `mask_preview.png` → 在任意图像编辑器里把残留涂黑 → 本工具后续版本支持 `--mask` 复用（**尚未实现，登记在 PENDING**）；
  ③ 直接裁掉残留区（图标场景最省事）。
