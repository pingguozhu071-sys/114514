# 08 · 扩展路径（"自己拓展"的扩展点）

> 一条判据贯穿全文：**加东西不该改核心形状**。如果一个扩展要动 `core/router.py` 的转移表，
> 那它就不是扩展，是要评审的架构变更。

## 一、加数据来源 = 加一个适配器文件

```python
# adapters/extractors/<site>.py
def match(url: str, evidence) -> bool: ...          # 精确域匹配（不要用模糊包含）
def extract(raw: bytes, meta: dict) -> dict:        # {"ok": bool, "error"?: str, ...}
```

- 注册即生效（注册表 + 兜底链路）；
- **直链使用前重过闸**：适配器里拿到的任何远端 URL 都是**不可信输入**，必须过 `net/fetch.py`；
- 站点专有逻辑永远不进核心（`docs/05` 的"不把站点当架构"）。

**契约测试**：`加一个来源只改一个文件` —— 门禁里有一条断言"新增适配器未触碰 core/`"。

## 二、加格式 = 加一个解析器文件

```python
# understand/parsers/<fmt>.py
def detect(data: bytes, meta: dict): ...            # 可选：参与探测链
def parse(data: bytes, meta: dict) -> dict:         # 同构返回 {"ok", "error"?, ...}
SPEC = ParserSpec(name="…", version=1, accepts=("…",), parse=parse, order=100)
```

- **先捕获后理解的红利**：注册后 `python -m daedalus reparse` 就能把**历史原始数据**重新解释一遍，
  **不重新联网**（门禁 S9 D1 断言"网络增量为 0"）；
- 解析器必须标 `version`：派生记录里会记下是哪个版本产出的，方便判断"要不要用新版本重跑历史"。

## 三、加采集方式 = 加适配器/执行资源（官方 API、授权数据源、外部工具）

实现 `FetchPort`（能 `open(url) -> response`），核心不改形状。已有的例子：
`net/fetch.py`（咽喉本体）、`env/resumable.py`（断点续传）、`adapters/hls.py`（分片并发）、
`exec/subprocess.py`（外部二进制）。

**红线**：任何新的取流方式都必须**过同一道闸与同一套礼貌预算**——"只要还有第二条出网路径，
闸和限速就不成立"（这是 S1 的原始教训）。

## 四、加环境 = **需评审（默认拒绝）**

必做四件事，缺一不可：

1. **独立资源账本**（在 `core/limits.py` 的 `ResourcePlan` 里加科目，参与内存自证）；
2. **独立生命周期**（自己启停、自己进关闭链，不依赖别的环境还活着）；
3. **自己的取流闸**（浏览器面就是范本：`env/browser.py` 的 `decide()` + route 逐条判定 + fail-closed）；
4. **独立预算科目**（墙钟/字节/转移都要能单独计数）。

做完写进 `core/registry.py`（容量默认 0 = 缺省即拒绝）与 `docs/02` 的不变量表，
并补一条端到端门禁（"被拦的 URL 进不了这个环境"是必须证明的一条）。

## 五、加存储 = 实现 `StoragePort`

原始层（内容寻址 + 幂等写）、元数据（SQLite 单写线程）、分析层（JSONL）各自都可替换。
**不变量**：原始层必须不可变且可重放；派生层必须可由原始层重建（换了存储也要成立）。

## 六、加外观预设 / 加面板 = 走设计系统的口子

- 预设：`ui/settings.py` 的 `save_preset/export_presets/import_presets`（JSON 往返）；
- 新面板：`ui/pages.py` 加一个 `_xxx(window, tokens, ctx)` 工厂 + 在 `PAGE_TITLES` 里注册；
  **样式必须走 `theme.card_qss()` 这一个生成器**（同页所有卡片同一来源，这是铁律）；
- 新控件不要自定义样式（控件层交给 Fluent 组件库，别逐控件改 QSS）。

## 七、异步那一格（刻意留着，但有启用判据）

`core/registry.py` 里 `async` 容量是 0（缺省即拒绝）。启用判据（写在 `PENDING.md` 待确认项）：

- 阻塞等待占比高（比如 >30% 的时间在等 IO 且线程数已到上限）；
- 或者需要长连接高并发（SSE/WS 同时几百条）。

启用时**必须**满足 `docs/02` 的第 1 条不变量："同一份共享状态不得被两种执行模型直接操作"
——异步侧不许直接写库，一律交给单写线程。

## 八、扩展时的四步自检（每次都要做）

1. **契约测试**：新东西的桩签名与真接口一致（否则门禁是假绿）；
2. **边界扫描**：`python tools/lint.py`（裸出网/动态 SQL/无界队列/对抗词汇/未登记 TODO）；
3. **门禁**：`python tools/gates.py`（改了核心必须全绿；只加适配器也不许红）；
4. **登记**：DEVLOG 写"做了什么/为什么/影响面"；未完成项进 PENDING。

## 九、明确不做的扩展（写下来省得反复讨论）

- 反检测/隐身/打码/签名伪造/出口轮换/行为拟人（`docs/07`）；
- 分布式爬虫集群（本工程是**单机**引擎；跨机需求走"便携版 + 各自数据根"）；
- 把 GUI 做成"操作台式的爬虫管理器"（它只是本引擎的一个显示面）。
