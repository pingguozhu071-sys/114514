# 02 · 路由与不变量

> 路由**不神化**：它是确定性策略引擎 + 有界状态机，只做四件事——识别、判断、选择、升级。
> 每次转移都给理由，理由落进证据链，事后可回放。

## 一、证据（路由的唯一依据）

`core/evidence.py`。信号集是**有界**的（新增信号必须同时想清楚路由怎么用它）：

| 信号 | 含义 | 典型去向 |
|---|---|---|
| `classified` | L0 分类结论 | → 直连 |
| `ok` | 拿到可用内容 | 直连阶段：终态 done；制品阶段：终态 done |
| `empty_content` | 空壳/质量不足 | → 浏览器（未启用则记候选并终止） |
| `media_manifest` | HLS/DASH 清单 | → 制品与媒体 |
| `large_object` | 大对象/未知二进制 | → 制品与媒体（或只捕获不解析） |
| `stream` | SSE/WebSocket | 记候选（协议适配器未启用） |
| `unknown_format` | 认不出的二进制 | 只捕获、延期解释 |
| `parser_failed` | 解析失败（原始已存） | **终态 done**（延期解释，不是失败） |
| `transient_failure` | 瞬时失败 | 退避重试（计 `attempts`） |
| `throttled` | 被限流 | 退避重试（计 `throttles`，**不计 attempts**） |
| `permanent_failure` | 404/410 | 死信 |
| `policy_denied` | robots/SSRF/需授权 | 终态 `policy_denied`（不可重试） |
| `budget_exceeded` | 预算耗尽 | 死信 |
| `resource_denied` | 资源缺省即拒绝 | 死信（附"要什么资源"） |
| `network_activity` | 浏览器观察到的网络活动 | 终态 done（新事实 → 可派生任务） |

**每条证据都带 `facts`**（可核对的值，不是推测）：状态码、声明类型、体积、最终 URL、重定向跳数、
质量分与原因、解析器与格式、被拦原因……

## 二、状态机（写死的转移表）

```
CLASSIFY ──▶ DIRECT ──┬─ ok ────────────────▶ DONE
   (L0)      (L1)     ├─ large_object/media ─▶ ARTIFACT ─┬─ ok ─▶ DONE
                      ├─ empty_content ─────▶ BROWSER ──┼─ ok/network_activity ─▶ DONE
                      ├─ stream ────────────▶ 记候选并终止
                      └─ parser_failed ─────▶ DONE（keep_raw：延期解释）
通用（与阶段无关）：policy_denied → 终态；throttled/transient → 退避重试；
                    permanent_failure / resource_denied / budget_exceeded → 死信
兜底：当前阶段没有匹配规则 → **明确失败（不猜）**，理由写清"什么信号没规则"
```

三条硬约束（`core/router.py` 里能看到）：

1. **转移有界**：超过 `max_transitions`（默认 8）→ 死信。防"坏目标变资源黑洞"。
2. **预算有界**：每个任务有墙钟/字节/转移/重试/限流五个维度（`core/budget.py`）。
3. **未启用的环境只记候选**：不偷偷起环境。

## 三、路由**不**做的事

- 不问"这是什么网站"（不猜站点，只看事实）；
- 不自己选环境（运行器也不选——只有 Router 选）；
- 不在证据不足时"聪明一下"（兜底是明确失败 + 可读理由）；
- 不因为失败就升级手段（失败是**路由信号**，不是"该上对抗了"）。

## 五、常见误解（写给未来的自己）

- **"重试"不是"再试一次"**：退避、抖动、上限、独立计数都要有，否则就是重试风暴。
- **"被限流"不是失败**：它是"对方在说慢点"，所以不进 `attempts`，也不该转死信——
  连续 N 次才转。
- **"解析失败"不是失败**：原始数据已经存下了，这是"延期解释"。
- **"没抓到"和"没变"是两回事**：`unchanged` 是一等结果（条件请求 304 复用旧内容），
  台账里必须区分。
- **"内容空壳"应先怀疑路由，而不是先加手段**：空壳是"直连拿不到渲染后的内容"这个事实，
  它指向浏览器环境，不指向"绕过"。
