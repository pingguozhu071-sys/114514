# 00 · 架构

> 权威源：`写作.txt`（最终裁决）> `可以.txt` > `Executive Summar.txt`。本文件是**落地后的实况描述**，
> 不是设计愿望——每一条都能在代码与门禁里找到对应物。

## 一句话

**一台不是爬虫的采集器**：不预先选一种架构，让不同采集方式成为同一系统里**可被调用的执行资源**，
由证据决定用哪条路；**抓到的东西先原样存下来**，之后随时可以重新解释。

## 顶层只有七样东西

| 顶层概念 | 落地位置 | 说明 |
|---|---|---|
| **Task**（不是 URL） | `core/task.py` | 一个任务可跨多个采集环境、会派生新任务，所以核心对象是任务 |
| **Policy** | `obs/policy.py` + 各环境 | 脱敏、robots、礼貌预算、边界声明 |
| **Evidence** | `core/evidence.py` | 路由的**唯一**依据；有界信号集；可回放（落库） |
| **Route** | `core/router.py` | 有界状态机，每次转移必须给理由 |
| **Resource** | `core/registry.py` + `core/limits.py` + `exec/pools.py` | 任务**显式声明**要什么；缺省即拒绝 |
| **Artifact** | `capture/rawstore.py` + `capture/artifacts.py` | 原始字节 + 契约验证后的产物 |
| **State** | `frontier/frontier.py` + `store/*` | 租约/CAS/心跳/看门狗/检查点 |

## 三个采集环境（只有三个）

| 环境 | 落地 | 什么时候被选中（证据） |
|---|---|---|
| ① 直连网络 | `env/net.py` + `net/fetch.py`（唯一咽喉） | 默认的最便宜路径；拿 `ok` 就结束 |
| ② 浏览器运行时 | `env/browser.py` | 直连拿到**内容空壳/质量不足**（`empty_content`），且它可用 |
| ③ 制品与媒体 | `env/media.py` + `adapters/hls.py` | `media_manifest`（HLS/DASH）或 `large_object`（大对象/未知二进制） |

**未启用的环境只记候选**：浏览器槽位默认 0，遇到空壳页就记 `browser_candidate` 并终止，
**不会偷偷起浏览器**（`core/router.py` 的 `_to_stage`）。

## 执行资源（线程不是架构）

`exec/pools.py`（有界队列 + 池 + 流水线）、`exec/subprocess.py`（外部工具面）、
`env/media.py` 的分片并发、`understand/parsers/mediainfo.py` 的**进程隔离**。

线程/进程/子进程是**资源**，路由按证据决定何时调用；异步那一格**刻意留着不启用**
（`core/registry.py` 里 `async` 容量 0 = 缺省即拒绝）。

**同一条不变量**：同一份共享状态不得被两种执行模型直接操作。写库只有一个写线程
（`store/writer.py`），所有写都经它。

## 闭环（一次任务的一生）

```
Task ──Router.start──▶ 决策 ──▶ 环境执行 ──▶ 证据 ──▶ Router.on_evidence ──┐
  ▲                                                                        │
  └──────────────── 转移（有界，每次都记理由）◀───────────────────────────────┘
                                    │ 终态
                                    ▼
        Frontier.commit_done（CAS + 产物 + 派生行，同一事务）
        Frontier.mark_failed（限流与重试**分别记账**） / Frontier.release（交还，不算失败）
                                    ▼
                        变更台账（new/unchanged/updated/failed/policy_denied）
```

落地：`core/runner.py`（TaskRunner）。它**不选环境**（那是 Router 的职责），
只把每一步落到实处；自身异常一律兜住并记死信。

## 捕获面与理解面（先捕获后理解）

- **捕获面**（`capture/`）：原始字节 + 头 + 血缘 → 内容寻址（sha256 分片目录）+ 元数据入库；
  **在解析之前**、**在质量判断之前**发生。截断的响应会标 `too_big`，不伪装成完整产物。
- **理解面**（`understand/`）：探测（魔数→扩展名→XML 根→Content-Type→文本→兜底）→
  解析注册表 → 规范化 → 质量闸 → 指纹（content_hash / simhash64）→ 变更台账。
  解析失败**不是失败**：`parser_failed` → `keep_raw` → 延期解释；新解析器注册后
  `daedalus reparse` 就能把历史原始数据重新解释一遍（**不联网**）。

## 存储三分

| 层 | 落地 | 说明 |
|---|---|---|
| 原始 blob | `raw_data/`（内容寻址 + 每记录 gzip） | 不可变；脱敏**永不**作用于它 |
| 元数据 | SQLite（WAL + 单写线程 + 批提交 + 每任务 SAVEPOINT） | 任务/前沿/证据/产物/派生/死信/冷却 |
| 分析 | JSONL（台账、指标快照、基准记录） | 可 diff、可管道、可回归对比 |

## 数据根（唯一规则）

`privacy/secrets.data_root()`：① `DAEDALUS_DATA_ROOT` 环境变量 → ② 便携（`portable.flag`
或同级 `DaedalusData/`）→ ③ 用户级 `%LOCALAPPDATA%\Daedalus`。
**绝不使用打包器的解包临时目录**（`sys._MEIPASS`）——那是升级时会被清掉的地方。

## 观测与生命周期

`obs/`：指标（有界、含 p50/p95/p99）、结构化日志（字段稳定、先脱敏后落盘、轮转）、
阈值告警、任务下钻、采样器（进程/磁盘）。
`core/lifecycle.py`：在飞任务**强引用** + 优雅关闭链（顺序写死、每步超时、失败不阻断、可重复调用）。

## 两个界面，一套装配

`core/app.py`（EngineApp）是**唯一的装配点**：CLI（`cli.py`）与 GUI（`ui/`）都从它拿组件，
两边差别只剩"怎么显示"。这避免了"一边接了浏览器、一边没接"的漂移。
