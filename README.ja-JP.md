# ダイダロス · Daedalus

**統合収集・観測エンジン（クローラーではありません）** — Universal Data Acquisition & Observation Engine

> 単機・Windows 対応。3 つの収集環境（直接ネットワーク / ブラウザ実行環境 / 成果物とメディア）は
> **呼び出し可能な実行リソース**であり、証拠駆動のルーターが「低コスト優先」（L0→L5）で経路を選びます。
> **まず捕獲、理解はその後**——生レイヤーは内容アドレス指定（sha256）で追記専用。新しいパーサーで
> 履歴データを**オフラインで**再解釈できます（`reparse`）。

## 概要

- **上位のエキスパートは 3 つ**：直接ネットワーク / ブラウザ実行環境 / 成果物とメディア。スレッド・プロセス・サブプロセス・ブラウザスロットは**実行リソース**にすぎず、ルーターが証拠とコストで判断します。
- **Task が中心オブジェクト（URL ではない）**：目標 / 範囲 / 予算 / **リソース宣言** / 証拠チェーン / 状態。1 つのタスクが複数環境をまたげます。
- **有界なルーティング**：遷移上限・予算尽きで停止、失敗はルーティングのシグナル（再試行と制限は別帳簿）；すべての遷移に証拠が付き、再生可能。
- **Capture First**：生レイヤーは内容アドレス指定・原子書き込み・削除なし。事実は失われません。
- **セキュリティ**：送信は唯一のゲート（SSRF 検査はホップ毎に再確認）、認証情報は DPAPI のみ、ログとエクスポートは**保存前にマスク**。

## クイックスタート · インストール

| 方式 | 手順 |
|---|---|
| インストーラー | `dist/Daedalus-Setup-<バージョン>.exe` をダブルクリック——完全ウィザード、**サイレントインストール禁止**；ライセンスページは 3 言語；デスクトップショートカットは任意 |
| ポータブル | `dist/daedalus/` をコピーし、隣に空の `portable.flag` を置くだけ。データは同階層の `DaedalusData/` に |

インストール後の自己証明：`daedalus-cli --json doctor` —— 使えるか・何が欠けているか・**UI 言語がなぜこれなのか**（`ui` セクション）を 1 コマンドで説明します。

## クイックスタート · CLI

```bash
daedalus-cli --json collect https://example.com/     # 収集（ドメイン別制限 + robots + SSRF ゲート）
daedalus-cli --json collect --dry-run https://example.com/   # 判定と計画のみ；network_calls=0 を実測で自己証明
daedalus-cli --json reparse                          # 現在のパーサーで履歴をオフライン再解釈
daedalus-cli --json export --out out.jsonl           # エクスポート（マスク済み）
```

サブコマンドは 10 個：`version / config / doctor / metrics / alerts / collect / reparse / export / search / ui`。
`--json` 時の stdout は **JSON のみ**、エンコードは常に **UTF-8**（コンソールのコードページに依存しない）。
終了コード：`0` 成功 / `1` 業務失敗 / `2` 用法 / `3`遮断 / `4` 内部エラー。

## GUI（`daedalus-cli ui`）

- **UI 言語**：設定 > インストーラーの選択 > システム言語 > en-US。タイトルバーの `English ｜ 简体中文 ｜ 日本語` リンクで即切換（ページ全体を再構築、混在言語なし）。
- **概要**：統計カード（数字がロール）+ 実行中のリソース計画 + **クイック収集**——目標を 1 行ずつ貼るか、**TXT をインポート**（壊れた行を除外・重複排除・ドメインごとにグループ化し「N 件取り込み（M 件無効、D 件重複）」と正直に報告）。
- **タスク**：行をダブルクリックで判断チェーン（証拠）を表示；**再試行 / 選択をエクスポート / 記録削除**——削除は先に確認、タスクと証拠行のみ削除、**生データは 1 バイトも触れません**。
- **ログ**：実データソース、**表示前にマスク**、上限 5000 行、レベル別の色分け。
- **外観**：壁紙からのスマート抽出、ガラス透明度 4 段階、密度 3 段階、動作の総スイッチ（オフ = 即座に最終状態）。

## 能力の境界

- **する**：セッション再利用、Cookie 取り込み（自分のセッションのみ）、ドメイン別レート制限 + ジッター + 適応バックオフ、遮断時は減速 → 停止 → 理由付きで報告。
- **しない**：ステルス注入 / 指紋偽装 / CAPTCHA 解読 / 署名偽造 / 出口ローテーション / 振る舞いの擬人化。
- 立場：**ユーザーがアクセス権を持ち、システムが合法的に観測できる**範囲で、可能な限り完全に収集・保存する。
